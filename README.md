# SecDesk-lite

Sistema web para gerenciamento de chamados de TI e incidentes de segurança, desenvolvido como projeto de aprendizagem e portfólio.

## Objetivo da V1

Implementar o ciclo completo de atendimento: abrir um chamado, acompanhar seu status, assumir o atendimento e concluir registrando a solução.

## Tecnologias

- **Back-end:** C# e ASP.NET Core Web API
- **Front-end:** React e TypeScript
- **Banco de dados:** SQL Server
- **Versionamento:** Git e GitHub

## Escopo da V1

- Abertura e consulta de chamados.
- Tipos: suporte de TI e incidente de segurança.
- Status: Aberto, Em andamento e Concluído.
- Atribuição de responsabilidade e registro da solução.
- Controle de acesso conforme o papel do usuário.
